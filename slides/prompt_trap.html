07 / The trap

Deep reasoning cannot fix an unclear prompt.

Audience scenario
“Fix the login bug.”
Ask the room: Which reasoning level would you choose?

First, ask for the missing pieces.

REPRODUCEWhat steps trigger the problem?
EXPECTEDWhat should happen instead?
ENVIRONMENTWhere does it happen: local, staging, production?
EVIDENCEWhat logs, errors, or recent changes exist?
Correct first move: clarify the task before escalating the reasoning level.
A better prompt makes every reasoning level more useful.
